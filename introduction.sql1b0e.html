Instructions

At the bottom of the main page, you will find a table listing all the registered resources. Each row displays a resource along with a brief description of what it is. Clicking on a row will take you to the linked page.

Filtering

To make it easier to find what you are looking for, you can filter the results. Use the magenta buttons to select the language of the resource. Use the orange buttons to select the type of resource; for example, if you are looking for a dictionary, you can select "Dictionary." Finally, you can filter by dialect region. If you are interested in Westphalian, for instance, you can simply select "Westphalia." However, it is worth checking all the options, as the results are sorted alphabetically rather than by relevance.

Language Selection

If you would like to use the site in a different language, you can tap English in the top right corner to switch languages.

Troubleshooting

If a link is broken, a category is incorrect, or there is a typo, please contact soeffker.plat@gmail.com. The same applies if you have any complaints regarding the content of a page.

Suggesting New Content

If you know of other relevant websites, I would be happy to receive them. Please send suggestions to soeffker.plat@gmail.com.

It would be very helpful if you could specify the dialect, language, and orthography used by the site, as well as a brief description of what the site offers.

About the Website

This website was created to make it easier to get started with Low Saxon. Based on my own experience, I found it difficult to know what to search for; that is why I have collected, categorized, and clearly presented a wide range of websites. Although the site is primarily designed for getting started with the language, it also offers added value for advanced learners looking for new content they might have previously missed.
